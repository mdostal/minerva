# Contributing to Minerva

Welcome to the Pantheon! We're thrilled you want to contribute to Minerva.

## Development Setup

1. Clone the repository
2. Run `npm install`
3. Run `npm run test` and `npm run typecheck` to verify your environment

## Pull Request Process

1. Ensure your code passes all tests and type checks.
2. Update the README.md with details of changes, if applicable.
3. Update the `docs/` where appropriate if you are changing architecture or adding features.
4. Open a PR against the `dev` branch.

## Code Standards

- **TypeScript**: We use strict TypeScript. `tsc --noEmit` must pass.
- **Tests**: Add tests for any new behavior.
- **Style**: Match the existing formatting and structure.

## Community

Minerva is a core part of the Pantheon ecosystem. Join discussions in our issues and PRs.
