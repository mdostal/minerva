Meet Minerva

Turns an idea into a spec and a plan, headless.
Free & open source.

curl -fsSL https://mdostal.github.io/minerva/install.sh | bash

Installs the CLI and wires Minerva into Claude Code & Codex CLI automatically.

What & why

Planning used to mean a human hand-running kickoff and plan in a terminal, one idea at a time. Minerva exists to make that step a service you can drive from anywhere — feed it an idea, and it drives the full kickoff+plan loop, surfaces exactly the questions that need a decision, and returns a finished spec.

Splitting the planner out of the terminal is what lets you feed many ideas at once: each idea gets its own Minerva run and its own decision thread, in parallel, instead of a serial per-idea session.

⚡

Async & parallelizable

Multiple ideas run concurrently — no terminal babysitting, no serial queue.

🔌

Subprocess ABI

JSON-over-stdio, one request in, one response out. No daemon, no port. Any language can call it.

🦉

Headless planning

Runs the kickoff + plan loop against an isolated git workspace. Only true human-gate questions escalate.

🔄

Swappable drivers

SpawnDriver, SubagentDriver, ForkedHiveDriver — toggle and compare planning strategies at will.
